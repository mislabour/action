Create a complete monetized URL shortener platform with the following specifications:

PROJECT OVERVIEW:
Build a multi-user link shortening service where publishers can register, create shortened links, and earn money from ad revenue displayed on interstitial pages. The platform owner shares ad revenue with publishers using a 70-30 split model.

CORE FUNCTIONALITY:

1. USER SYSTEM:
- Public homepage with registration/login forms
- Three user types: Admin, Publishers, and Visitors
- Publisher registration with email verification
- Secure login/logout system with session management
- Password reset functionality via email
- Publisher dashboard showing earnings, clicks, links, and withdrawal options

2. LINK SHORTENING ENGINE:
- URL validation and sanitization system
- Unique short code generator (6-8 characters alphanumeric)
- Database table storing: short_code, long_url, publisher_id, created_date, click_count, earnings
- API endpoint for programmatic link creation
- Bulk URL shortener (up to 20 URLs at once)
- Custom alias option for premium users

3. INTERSTITIAL AD PAGE:
- Full-page ad display before redirect to destination
- Countdown timer (8-10 seconds) before showing Continue button
- Placeholder for OnClickA JavaScript ad code in <head> section
- Multiple ad unit support (banner + video + popunder)
- Clean, professional design with progress indicator
- Mobile-responsive layout
- Geographic targeting capability (show different ads by country)
- 302 temporary redirect (not 301 permanent) to destination URL

4. REVENUE TRACKING SYSTEM:
- Real-time click tracking with IP logging and fraud detection
- Country/device/browser detection for each click
- Automatic earnings calculation based on CPM rates
- Publisher earnings = (total_revenue × 70%)
- Platform earnings = (total_revenue × 30%)
- Configurable CPM rates by admin (default $5 CPM for Tier 1 countries)
- Geographic-based CPM rates (US/UK/CA higher than other countries)

5. PUBLISHER DASHBOARD:
- Overview page with today's stats, total earnings, pending balance
- All shortened links list with individual click stats
- Date range filter for analytics
- Top performing links section
- Country breakdown chart showing click origins
- Device statistics (desktop vs mobile vs tablet)
- Referrer tracking (where clicks came from)
- Earnings graph showing daily/weekly/monthly trends
- Profile settings page (email, password, payment info)

6. PAYMENT/WITHDRAWAL SYSTEM:
- Minimum withdrawal threshold (configurable by admin, default $5)
- Payment methods: PayPal, Bank Transfer, Bitcoin, USDT
- Withdrawal request system with admin approval queue
- Payment history page showing completed and pending withdrawals
- Automatic email notifications for withdrawal requests and approvals
- Monthly earning reports sent via email

7. ADMIN PANEL:
- Dashboard with total users, links, clicks, revenue statistics
- User management (view, edit, ban, delete publishers)
- Link moderation system with blacklist capability
- Withdrawal approval/rejection interface
- Site settings: minimum payout, revenue share percentage, CPM rates by country
- Ad code management (paste OnClickA code once, applies to all interstitials)
- Multiple interstitial page templates editor
- Ban list for malicious URLs or publishers
- Analytics overview with charts and graphs
- Email template editor for notifications

8. PUBLIC PAGES:
- Homepage with hero section explaining the service
- "How It Works" section with 3-4 step visual guide
- Pricing/Plans page (Free and Premium tiers)
- Statistics page showing total links created, total clicks, happy publishers
- FAQ page answering common questions
- Terms of Service page
- Privacy Policy page
- Contact Us page with contact form
- About Us page

9. SECURITY FEATURES:
- SQL injection prevention with prepared statements
- XSS attack protection with input sanitization
- CSRF token implementation for forms
- Rate limiting on link creation (prevent spam)
- Bot detection and blocking on interstitial pages
- IP-based fraud detection (flag suspicious clicking patterns)
- Secure password hashing with bcrypt
- HTTPS enforcement
- Session hijacking prevention

10. ADDITIONAL FEATURES:
- Referral system (publishers earn 5% of referred publisher's earnings)
- QR code generator for each shortened link
- Link expiration dates (optional)
- Password-protected links option
- Link editing capability (change destination URL)
- Link statistics API for developers
- Browser extensions support planning
- Social sharing buttons on interstitial pages
- Custom domain support for premium users
- Bio pages/Link-in-bio feature (like Linktree)

TECHNICAL REQUIREMENTS:

Backend: PHP 8.0+ with MySQL database
Frontend: HTML5, CSS3, JavaScript (jQuery or vanilla)
Framework: Use Laravel or CodeIgniter for MVC structure
Database: MySQL 5.7+ with proper indexing on short_code and publisher_id columns
Caching: Redis or Memcached for popular links
Server: Apache with mod_rewrite enabled for clean URLs
Responsive Design: Mobile-first Bootstrap 5 framework
Charts: Chart.js for analytics visualizations

DATABASE STRUCTURE:

Table 1 - users:
id, username, email, password_hash, registration_date, account_type, balance, total_earnings, payment_email, payment_method, status, api_key

Table 2 - links:
id, short_code, long_url, user_id, created_at, updated_at, clicks, total_earnings, status, custom_alias, expiry_date, password_hash

Table 3 - clicks:
id, link_id, short_code, user_id, click_date, ip_address, country, device_type, browser, os, referrer, earnings

Table 4 - withdrawals:
id, user_id, amount, payment_method, payment_email, request_date, status, admin_notes, processed_date

Table 5 - settings:
id, setting_key, setting_value (store CPM rates, revenue share %, min payout, etc.)
